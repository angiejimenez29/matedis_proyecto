# Envío seguro y confiable de mensajes

Proyecto final de Matemática Discreta (Valery y Angie).

Flujo de la app: **cifrar → codificar → ruido → corregir → descifrar**

## Estructura
- `src/cifrado.py` – César y Vigenère (Valery)
- `src/ruido.py` – simulación de ruido (Valery)
- `src/hamming.py` – codificación y decodificación Hamming(7,4) (Angie)
- `src/main.py` – menú principal que une los módulos (Valery)
- `docs/` – informe y presentación
- `capturas/` – capturas de la app funcionando

## Ejecutar
```
python src/main.py
```
